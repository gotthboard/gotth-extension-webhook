# gotth-extension-webhook v1.0.0

First stable candidate for the bounded, out-of-process GOTTH Mail HTTPS webhook alert extension.

## Stable contract

- Uses gotth-extensions v1.0.0 for manifest, grant, and session contracts and gotth-sdk v1.0.0 for generated extension-control V1 messages/services, without module replacement or a repository-local control copy.
- Preserves the released control and notification wire protocols, configuration, alert, secret-slot, and HTTPS/HMAC contracts. The protected runtime binding now carries the canonical grant and host profile so the extension can derive and enforce the authoritative negotiated session; digest-only alpha bindings must be regenerated by the host.
- Retains alert-only authority, deterministic bounded JSON, TLS 1.2+, disabled redirects, no hidden retries, bounded evidence, and fail-closed prompt and mutation behavior.
- Correctly rejects actual Unicode line/paragraph separators in values used by JSON and HTTP boundaries.

## Release bundle

A final clean build produces the Linux/amd64 archive, SPDX 2.3 SBOM, in-toto Statement v1 / SLSA provenance v1, and external checksums. The archive includes source checksums, internal checksums, third-party notices, and verbatim license files for the exact linked module graph.

## Upgrade

Follow docs/upgrade-v1.0.0.md. GOTTH Mail must stage v1.0.0 beside the retained prior artifact and prove A→B→A with routing closed during transition. Do not relabel an alpha archive or bypass an immutable digest pin.

## Admission status

This document describes an untagged candidate, not a published release. Producer admission requires revision-matched extension checks, two fresh clean reviews, a clean commit, and authorized Forgejo tag/Release publication. GitHub publication is Bryce's later handoff. Mail A→B→A runs after all four extension releases as consumer integration and is not bypassed or treated as a Forgejo publication gate.
