# v1.0.0 stable candidate

Promotes the alpha.2 implementation to its own stable 1.0.0 identity without changing the released V1 protocol/interface, configuration, alert, or secret contracts. The protected binding is tightened to carry authoritative grant and host data for local session derivation. Adds exact stable acceptance, compatibility, dependency/license, SBOM/provenance, upgrade/rollback, and deterministic release-bundle machinery.

The relative-output defect is repaired by resolving the caller's output path before entering the immutable export and by comparing all four relative-path assets byte-for-byte with the absolute-path build. The later final review also found that malformed UTF-8 could be rewritten by `encoding/json` and that complete matrix evidence had been carried from an older tree; the shared object decoder now rejects malformed bytes before decoding and the final matrix must be rerun and sealed against the exact corrected commit. Release completion also requires two fresh clean reviews of that commit and bundle, an annotated `v1.0.0` tag peeling to it, and published-mode canonical Forgejo closeout. Publication remains separately authorized. GitHub is Bryce's post-Forgejo handoff. Mail source and immutable pins are not changed or waived; Mail A→B→A follows all four extension releases as consumer integration.
